# Angry-Birds-Go-Music-Mod
A mod for the (ancient) mobile game Angry Birds Go! adding Mario Kart music and QOL improvements. Android only, requires extra steps to be taken to play on versions after Android 13.

Changes:
-Music replaced
-Energy (cupcake) system now faster to recharge
-All karts now 1 coin or gem
-Gems and coins are easier to earn

Known problems:
-Global multiplayer does not work
-Weekly tournaments do not work either
